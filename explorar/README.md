# QuantumMusicLab v0.4.1

**Desarrollado por Julio Zaldívar · aka m0m0 · y Ale Escárcega**

## Novedades
- Estado preparado guardable y restaurable.
- Medición individual con colapso.
- Experimentos de múltiples shots sobre qubits preparados en el mismo estado.
- Barras y porcentajes experimentales.

## Prueba
1. Configura x=1, y=0, z=0.
2. Guarda el estado actual.
3. Ejecuta 100 o 1000 mediciones.
4. Los resultados deberían aproximarse a 50/50.
5. Usa Medir qubit para observar un colapso individual.
6. Usa Restaurar estado para volver al estado preparado.
